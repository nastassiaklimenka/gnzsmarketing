# Skill: Создать изображение для поста 

## 🎯 Цель
Создать изображение для поста Telegram-канала на основе текста поста, строго соблюдая:
- брендбук
- tone of voice
- визуальную стилистику канала
- референс (образец изображения)

Изображение должно быть готово для публикации без дополнительной доработки.
