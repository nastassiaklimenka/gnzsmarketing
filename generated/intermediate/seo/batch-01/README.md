# Batch 01

Этот батч рассчитан на 5 статей.

Структура:

- `01_clusters` - согласование 5 кластеров
- `02_research` - исследования по утвержденным кластерам
- `03_articles` - тексты статей
- `04_tilda` - карты верстки под Tilda

Переходы между этапами:

1. Сначала утверждаются 5 кластеров.
2. Потом утверждаются исследования.
3. Потом утверждаются тексты.
4. Потом готовятся карты верстки и публикация.

Никаких молчаливых `OK` нет.
