# Batch 01

Этот батч рассчитан на 1 итерацию: 1 кластер, 1 исследование, 1 статья, 1 карта верстки.

Структура:

- `cluster_candidates.csv` - сырой список кандидатов кластера
- `cluster_review.md` - файл согласования кластера
- `research_<cluster_slug>.md` - исследование спроса и выдачи
- `article_<cluster_slug>.md` - текст статьи
- `tilda_map_<cluster_slug>.md` - карта верстки под Tilda

Переходы между этапами:

1. Сначала утверждается кластер.
2. Потом утверждается исследование.
3. Потом утверждается текст.
4. Потом готовится карта верстки и публикация.

Никаких молчаливых `OK` нет.
