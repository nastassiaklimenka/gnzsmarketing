# Agents Guide (agents.md)

## Что это за репозиторий
- Репозиторий хранит материалы для маркетинга/брендинга (брифы, гайды, задачи, визуалы и другие документы).
- Ключевая ценность: сохранить структуру и исходные материалы, чтобы они оставались понятными для редактирования и передачи между людьми и ИИ.

## Базовая картина корня
- **README.md** — краткое описание проекта.
- **Брендбук/** — брендовые/дизайн-материалы.
- **Картинки амо/** — графические файлы.
- **Кронос/** — связанные материалы.
- **Продукты Генезис/** — контент по продуктам.
- **Системный лидген/** — материалы по лидогенерации.
- **Файлы форматов `.docx` и `.xlsx`** — документы и таблицы с исходным контентом.

## Рекомендуемый рабочий процесс
1. Перед правками зафиксируй задачу и её цель в коротких комментариях/задачах.
2. Перед сменой документа работай только с тем файлом, который реально меняется.
3. Сохраняй исходные версии файлов (не удаляй оригиналы без явной договоренности).
4. Не переименовывай папки и не удаляй файлы массово без подтверждения — это может сломать навигацию по материалам.
5. Для файлов с кириллицей используй аккуратные имена и не меняй кодировку случайно.

## Сгенерированные файлы
- `generated/intermediate/` — промежуточные рабочие материалы: черновики, варианты, временные выгрузки, файлы для доработки, удаления или бэклога. Эти файлы не коммитить.
- `generated/final/` — итоговые материалы, которые команда берет в работу. Эти файлы можно коммитить после проверки.
- Если материал еще обсуждается или может быть заменен, сохранять его в `generated/intermediate/`.
- Когда материал утвержден как рабочий результат, переносить его в `generated/final/` или в профильную папку проекта, если это удобнее для дальнейшей работы.
- Для каждой задачи внутри этих папок создавать отдельную подпапку с понятным названием.

## Правила работы с контентом
- Для текста и правок в `.docx` лучше сохранять существующий тон бренда и терминологию.
- Для таблиц (`.xlsx`) менять только согласованные блоки: структура колонок и формулы/форматирование — только при необходимости.
- Графику (`.png/.jpg`) переносить и переименовывать только с обновлением каталога и короткой пометкой о новом формате/назначении.

## Что считать критичным к контролю
- Потеря исходных источников (источники должны оставаться в репозитории).
- Несогласованное переименование директорий.
- Заменa файлов с высоким уровнем влияния на бренд без проверки смыслового соответствия.
- Некачественные массовые изменения в русскоязычных названиях файлов/папок.

## Рекомендуемый формат ответов при выдаче правок
- Коротко описывать, что изменено и почему.
- При работе с несколькими документами указывать список файлов и цель каждой правки.
- Если есть риск потери данных — сразу предупреждать и просить подтверждение.

## Контакты и зона ответственности (внутренний регламент)
- Все изменения должны быть ориентированы на точность формулировок и сохранение брендовых смыслов.
- Если задача неочевидна (например, глобальная правка всей линейки документов), сначала согласовывай план шагов.
