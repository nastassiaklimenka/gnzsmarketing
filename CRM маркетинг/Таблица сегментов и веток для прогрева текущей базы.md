# Таблица сегментов и веток для прогрева текущей базы

Дата: 2026-08-20

## Логика таблицы

- `Сегмент` = Активные или Спящие.
- `Подсегмент` = лицензии / SaaS / ПВ / без покупок.
- `Ветка` = главная продуктовая логика касания.
- `Что отправляем` = какой тип касания или оффер получает этот сегмент.

## Что именно отправляем по веткам

| Ветка | Первый тип касания | Смысл первого касания | Второй шаг | Куда ведем |
|---|---|---|---|---|
| Лицензии -> сопровождение | Письмо / рассылка / сообщение | У вас уже есть amoCRM, но ее нужно развивать и донастраивать под реальные процессы | Разбор текущей CRM, карта доработок, бот | Встреча с проектным отделом / аудит / сопровождение |
| SaaS -> Прометей | Письмо / рассылка / сообщение | Отдельные виджеты закрывают частные задачи, а Прометей собирает процесс целиком | Разбор ручного процесса, бот, схема автоматизации | Встреча / разбор процесса / продажа Прометея |
| ПВ -> проектная продажа | Персональное письмо / персональное касание | Мы уже обсуждали развитие CRM, можно вернуться к этому разговору | Актуализация задачи, встреча, аудит | Сделка в проектный отдел |
| Реактивация | Серия писем / касаний | Напомнить, какие задачи решает Генезис и почему это может быть актуально сейчас | Диагностика, аудит, бот | Встреча / аудит / первая проектная продажа |

## Короткая фиксация по частоте

| Сегмент | Частота | Формат |
|---|---|---|
| Активные | 1-2 касания в месяц | Точечные полезные касания, апсейл, кроссейл, перевод в бота |
| Спящие | 4-5 касаний за 1 месяц, затем пауза 45-60 дней | Серия на возврат интереса, реактивацию, вывод на аудит или встречу |

## Главная фиксация

Для всей базы достаточно держать простую рабочую структуру:

- `Активные / Спящие`;
- `Лицензии / SaaS / ПВ / Без покупок`;
- `Размер по пользователям amoCRM`;
- `Что им отправляем`;
- `Куда ведем: бот / аудит / встреча / проектная продажа`.
